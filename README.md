# daglo (다글로) 대체 서버 + 녹음 태블릿 앱

강의·회의 녹음을 넣어 두면 Gemini 로 받아쓰고, 웹에서 스크립트 편집·요약·AI 채팅까지 하는
개인용 FastAPI 서버입니다. 태블릿으로 녹음해서 이 서버로 바로 보내는 안드로이드 앱(`app/`)이
함께 들어 있습니다.

## 실행

```bash
pip install -r requirements.txt
python run_server.py
```

- 설정은 `.env` 에 둡니다 (`.env.example` 참고). 처음 켜면 콘솔에 안내되는 로그인 주소에서
  첫 관리자 계정을 만듭니다.
- 다른 기기(같은 와이파이)에서 접속하려면 `.env` 에 `HOST=0.0.0.0` 을 두고, PC 의 내부 IP
  (`ipconfig` → IPv4, 예: `192.168.0.10`)로 `http://192.168.0.10:8000` 에 들어갑니다.
- 인터넷에 열어 둔다면 `LOGIN_PATH` 를 임의 문자열로 바꾸고, HTTPS(리버스 프록시)와
  `COOKIE_SECURE=1` 을 쓰는 것을 권장합니다.

## 폴더

| 경로 | 무엇 |
|---|---|
| `녹음파일원본/[폴더명]/` | 원본 녹음. 여기에 파일을 넣으면 서버가 알아서 받아쓰기를 시작합니다 |
| `강의 녹음 변환/` | 변환 결과 텍스트 |
| `휴지통/` | 웹에서 지운 녹음이 옮겨지는 곳 (복원하면 원래 자리로 돌아갑니다) |
| `server/` | FastAPI 서버 (`main.py`, `ai_service.py`, `auth.py`, `static/` 웹 화면) |
| `app/` | 태블릿 앱 (웹 화면 + 녹음) — 아래 [태블릿 앱](#태블릿-앱-녹음-전용--웹-화면) |

## 웹에서 폴더 지우기
왼쪽 폴더 목록에서 폴더 위에 마우스를 올리면 나오는 휴지통 아이콘을 누릅니다.
안에 보드가 있으면 어떻게 할지 고를 수 있습니다.

| 고른 것 | 서버 동작 |
|---|---|
| 보드는 기본 폴더로 | 보드를 살려서 `기본 폴더` 로 옮깁니다. 원본 녹음과 변환 텍스트(동반 파일 포함)도 함께 옮겨집니다 |
| 보드도 휴지통으로 | 보드를 휴지통으로 보냅니다. 파일은 `휴지통` 폴더로 옮겨지므로 **휴지통에서 복원하면 원래 자리로 되돌아옵니다** |

- 탐색기의 폴더(`녹음파일원본`·`강의 녹음 변환` 양쪽)도 함께 정리합니다. 파일을 남겨 두면
  감시 스레드가 그 파일을 보고 지운 폴더를 곧바로 다시 만들어 내기 때문입니다.
- 서버가 모르는 파일이 남아 있으면 그 폴더는 지우지 않고 그대로 둡니다 (직접 넣어 둔 파일일 수 있으므로).
  이때는 화면에 몇 개가 남았는지 알려 줍니다.
- `기본 폴더` 는 지울 수 없습니다. 폴더 전용 단어장은 폴더와 함께 정리됩니다.

## 서버 폴더를 탐색기에서 직접 건드릴 때
서버 PC 의 `녹음파일원본` 폴더는 탐색기로 그냥 만지셔도 됩니다. 서버가 5초마다 확인해서 반영합니다.
기다리기 싫으면 웹 화면 오른쪽 위 **`새로고침`** 버튼을 누르세요. 그 자리에서 폴더를 한 번 훑어
새 녹음·이름변경·이동·삭제를 바로 목록에 반영합니다. (버튼을 연달아 눌러도 보드가 중복으로 생기지 않습니다)

| 탐색기에서 한 일 | 서버 동작 |
|---|---|
| 녹음 파일을 넣음 | 새 보드로 등록하고 자동으로 받아쓰기 시작 (복사가 끝난 것을 확인한 뒤) |
| 파일 이름 변경 | **같은 보드의 제목만 바뀝니다.** 다시 받아쓰지 않고 기존 스크립트를 그대로 유지 |
| 다른 폴더로 이동 | **같은 보드가 그 폴더로 따라갑니다.** 역시 다시 받아쓰지 않습니다 |
| 파일 삭제 | 보드를 휴지통으로 보냅니다 (연속 3회 안 보일 때 — 네트워크 드라이브가 잠깐 끊긴 것과 구분). `.env` 에서 `FILE_DELETE_SYNC=permanent` 로 두면 보드와 변환 텍스트(`.txt`·`_강의스크립트.html`)까지 곧바로 완전 삭제합니다 |
| 지웠던 파일을 다시 넣음 | 휴지통에서 보드를 되살립니다 |

- 이름변경/이동은 파일의 **수정시각**이 같은 것을 단서로 알아냅니다. 같은 시각의 후보가 둘 이상이면
  안전하게 새 보드로 등록합니다.
- 변환 결과 텍스트(`강의 녹음 변환/...`)는 예전 이름 그대로 남습니다. 웹에서 보는 스크립트는
  DB 에 있으므로 영향이 없습니다.
- 한 번의 확인에서 너무 많은 파일이 사라졌다면(기본 50개) 저장소 장애로 보고 아무것도 지우지 않습니다.

## 태블릿 앱 (녹음 전용 + 웹 화면)

`app/` 에 안드로이드 앱이 있습니다. **갤럭시 탭 S8+ 기준**으로, 태블릿을 강의 녹음기로 쓰고
녹음이 끝나면 이 서버로 자동 전송하는 것이 이 앱의 일입니다.

- **첫 화면은 daglo 웹 화면(WebView)** 입니다. 로그인·보드 목록·스크립트 편집·요약·AI 채팅은
  전부 웹에서 그대로 합니다. 앱이 웹 대신 하는 일은 **녹음** 하나뿐입니다.
- 상단바의 **`녹음`** 버튼으로 녹음 화면에 들어가 폴더를 고르고 녹음합니다.
  파일명은 `[폴더이름]_20260906_143205.m4a`, **폴더 이름이 그대로 서버 폴더 이름**이 됩니다.
- 정지하면 자동으로 올라가고, 목록에 `전송 대기 중 / 전송 중 / daglo 로 전송됨 / 전송 실패`가
  파일마다 표시됩니다. 실패한 줄을 누르면 다시 보냅니다.
- 로그인은 웹 화면에서 한 번만 하면 됩니다. 그때 받은 세션 쿠키를 업로드가 함께 씁니다
  (앱에 비밀번호나 API 토큰을 저장하지 않습니다).

### 화면을 끄고 몇 시간 녹음하기

브라우저(크롬)에서 녹음하면 화면을 끄는 순간 탭이 재워지거나 메모리 회수로 죽어서 녹음이
사라집니다. 그래서 녹음만은 앱이 직접 합니다.

| 대비 | 어떻게 |
|---|---|
| 앱이 백그라운드로 가도 녹음 유지 | 포그라운드 서비스 + **녹음 중 알림**(경과 시간·일시정지·정지) |
| 화면을 꺼도 CPU 가 잠들지 않음 | 녹음 중 부분 웨이크 락(`PARTIAL_WAKE_LOCK`) |
| 삼성 절전이 앱을 재우는 것 | 설정 화면의 **`배터리 최적화에서 제외하기`** 를 한 번 눌러 두기 |
| 앱이 죽어도 녹음 보존 | 약 17분 조각으로 나눠 저장하고, 다음 실행 때 남은 조각을 자동으로 합쳐 되살림 |

> 처음 쓸 때 **꼭 한 번은 실제로 3시간 테스트**해 보세요: 녹음 시작 → 화면 끄고 방치 →
> 알림에 시간이 계속 올라가는지 확인 → 정지 → 목록에 `daglo 로 전송됨` 이 뜨는지.
> 제조사 절전 정책은 기기·펌웨어마다 달라서, 실제 기기에서 한 번 확인하는 것이 가장 확실합니다.

### 쓰기 시작하기
1. APK 설치 → 앱 실행 → 상단바 톱니바퀴(⚙)
2. **서버 주소** 입력 (`192.168.0.10:8000`, `http://` 생략 가능) → `연결 테스트` → `저장`
   - 서버 `.env` 에서 `LOGIN_PATH` 를 바꿔 뒀다면 **그 경로까지** 적습니다:
     `192.168.0.10:8000/gate-7f21c9`. 안 적으면 로그인 화면 대신 `Not Found` 가 뜹니다.
     (앱은 저장할 때 이 경로를 갈라 두므로, 업로드가 쓰는 `/api/...` 주소에는 섞이지 않습니다)
3. **배터리 최적화에서 제외하기** 를 눌러 허용
4. 뒤로 나와 웹 화면에서 웹과 같은 계정으로 로그인
5. 상단바 `녹음` → 폴더 선택 → 녹음

### APK 만들기
`main` 에 push 하면 GitHub Actions(`.github/workflows/build-apk.yml`)가 자동으로 빌드합니다.
Actions 탭의 최신 실행에서 `VoiceRecorder-debug-apk` 아티팩트를 받아 설치하세요.
(Android Studio 에서 `Build → Build APK(s)` 로 직접 만들어도 됩니다)

## 외부 클라이언트로 파일 올리기

`POST /api/boards/upload` 에 multipart 로 `file` 과 `folder_id`(또는 `folder_name`)를 보내면
바로 변환 큐에 들어갑니다. 인증은 둘 중 하나입니다.

- 로그인 세션 쿠키 (`daglo_session`) — 웹과 같은 계정
- `.env` 의 `DAGLO_API_TOKEN` 을 `X-API-Key` 헤더로 (자동화 스크립트용)

`folder_name` 으로 보내면 서버에 같은 이름의 폴더가 없을 때 자동으로 만듭니다.
