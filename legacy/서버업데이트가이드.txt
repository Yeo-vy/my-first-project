==========================================================================
 서버 업데이트 가이드 (claude 분석.txt 반영 — 2026-08-24)
==========================================================================

받아쓰기py.py와 안드로이드 앱 코드는 이미 개선되어 있다.
아래는 Azure VM(서버)에서 직접 실행해야 하는 작업만 모아 놓은 순서서이다.
위에서부터 차례대로 따라 하면 된다.


--------------------------------------------------------------------------
[1단계] systemd 로케일 설정 — 한글 파일명 'ascii' codec 오류 해결
--------------------------------------------------------------------------

systemd 서비스는 유저 셸 환경(LANG 등)을 물려받지 않아 LANG=POSIX(=ascii)로
떠서 pydub→ffmpeg가 한글 경로를 못 다룬다. file-watcher 서비스에 로케일을
강제로 지정해준다.

    sudo systemctl edit file-watcher.service

열리는 편집기에 아래 내용을 그대로 입력한다:

    [Service]
    Environment=LANG=C.UTF-8
    Environment=LC_ALL=C.UTF-8
    Environment=PYTHONUTF8=1

저장 후 적용:

    sudo systemctl daemon-reload
    sudo systemctl restart file-watcher.service

적용 확인 (LANG=C.UTF-8 이 보이면 성공):

    systemctl show file-watcher.service -p Environment


--------------------------------------------------------------------------
[2단계] 기존 청크 캐시 정리 — 청크 규격 변경(60분 → 20분+30초오버랩)
--------------------------------------------------------------------------

새 스크립트는 세이브포인트 파일명을 "_chunk_0of3.txt" 처럼 총 개수를 포함해
만든다. 예전 규격("_chunk_0.txt")의 캐시는 재사용되지 않으므로 남겨두면
그냥 찌꺼기가 된다. 미완료 파일의 옛 캐시를 지운다:

    find ~/받아쓰기폴더/강의\ 녹음\ 변환 -name "*_chunk_*.txt" -delete

※ 완료된 파일(최종 .txt + _강의스크립트.html 이 둘 다 있는 것)은 재변환되지
  않으니 걱정 없음. 실제 받아쓰기 폴더 경로는 서버에 맞게 조정할 것.


--------------------------------------------------------------------------
[3단계] 자막 저장 서버 배포 — HTML 편집 → txt 실시간 저장
--------------------------------------------------------------------------

(1) 패키지 설치

    pip install fastapi uvicorn

(2) 인증 토큰 발급 및 .env 추가

    임의의 긴 문자열을 만들어 .env 에 두 줄을 추가한다:

        echo "SAVE_TOKEN=$(openssl rand -hex 16)" >> ~/받아쓰기폴더/.env
        echo "GEMINI_API_KEY_PAID=" >> ~/받아쓰기폴더/.env   # 유료 키 있으면 값 입력

    - SAVE_TOKEN 을 비워두면 인증 없이 동작하니 공개 서버에서는 반드시 설정.
    - GEMINI_API_KEY_PAID 는 선택사항. 값이 있으면 무료 키 429 시 자동 전환됨.

(3) 테스트 실행 (포그라운드)

    cd ~/받아쓰기폴더
    uvicorn 자막저장서버:app --host 0.0.0.0 --port 8900

    브라우저에서 확인:
      http://서버IP:8900/view/Default/파일명_강의스크립트.html?token=발급한토큰

    HTML에서 아무 문장이나 수정하면 토스트에 "서버에도 저장되었습니다" 표시.
    서버의 .txt 를 열어 내용이 바뀌었는지 확인.

(4) systemd 서비스 등록 (24시간 상시)

    sudo nano /etc/systemd/system/subtitle-save.service

    [Unit]
    Description=Subtitle Save Server (HTML edit -> txt)
    After=network.target

    [Service]
    WorkingDirectory=/home/yeovy/및_실제_받아쓰기폴더_경로
    ExecStart=/usr/bin/python3 -m uvicorn 자막저장서버:app --host 0.0.0.0 --port 8900
    Restart=on-failure
    Environment=LANG=C.UTF-8
    Environment=LC_ALL=C.UTF-8
    Environment=PYTHONUTF8=1

    [Install]
    WantedBy=multi-user.target

    ※ WorkingDirectory 와 python 경로는 실제 환경에 맞게 수정
      (python 경로 확인: which python3)

    활성화:

        sudo systemctl daemon-reload
        sudo systemctl enable --now subtitle-save.service
        journalctl -u subtitle-save.service -f     # 로그 확인

(5) 방화벽 포트 열기 (ufw 사용 중인 경우)

    sudo ufw allow 8900/tcp
    # Azure NSG(네트워크 보안 그룹)에서도 8900 인바운드 규칙을 추가해야 한다.


--------------------------------------------------------------------------
[4단계] end-to-end 최종 점검
--------------------------------------------------------------------------

1. 짧은 오디오(5분 내외)를 my_files 에 올린다.
2. file-watcher 로그 확인:
       journalctl -u file-watcher.service -f
3. 받아쓰기 로그에서 확인할 것:
   - "총 N개의 조각" (20분 단위 + 마지막 조각)
   - 각 조각이 오류 없이 통과
4. 결과물 확인:
   - 타임스탬프가 이전 조각과 겹치지 않는지 (오버랩 중복 제거 동작)
   - HTML에서 문장 수정 → "서버에도 저장되었습니다" 토스트 → .txt 반영 확인
